# Attest

Attest is an open, privacy-preserving assurance substrate for businesses and people.

The protocol represents authenticated assertions, scoped authority, private evidence graphs, machine-readable requirements, and cryptographic presentations that prove a requirement is satisfied without disclosing unnecessary source data.

Initial proof-of-concept domains:

- business insurance assurance,
- SOC 2 assurance,
- ISO 9001 certification chains.

Implementation work lives on feature branches and is reviewed through pull requests.
